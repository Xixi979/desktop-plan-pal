# 桌面计划小人 (Desktop Plan Pal)

> 一只住在桌面上的「计划小人」——你随手丢给它计划，它结合你的课表和精力强度，自动把时间排好，并在合适的时候提醒和陪伴你。

**状态**：✅ v0.2 单机完整版（排程引擎 + 数据层 + Web 界面 + 小人动画 + LLM 双路由 + 增量重排；桌面打包进行中）

桌面宠物（陪伴层）× 自动排程引擎（功能层）的融合产品。市面上的桌宠只有"萌"，日历工具只有"格子"——我们把两者结合：小人既是形象入口，也是排程结果的执行者。

## ✨ v0.2 新增

- **小人动画（Sprite + 状态机）**：SVG 小机器人六种状态——待机呼吸眨眼 / 工作敲击 / 休息摇摆端茶 / 达标跳跃庆祝 / 超载流汗 / 深夜打瞌睡，状态由你的计划数据自动驱动
- **增量重排**：新加计划、勾达标只「补排」，不打乱正在做的事和手动调整过的安排；课表/撤销/导入才整体重排
- **自然语言 LLM 双路由**：一句话加计划默认本地规则解析（时长/时刻/DDL/优先级/类别）；可在「强度参数 → 🤖 AI 智能解析设置」填 OpenAI 兼容接口，AI 理解复杂表达，8 秒超时或失败自动退回规则版
- **计划文件夹联动**：支持浏览器直接选择文件夹并列出资料清单（File System Access API）；复制路径一键化

## ✨ v0.1 已实现

- **三种加计划方式**：一句话（自动识别时长/DDL/类别）、图片（OCR 识别生成达标要求）、链接（B站/GitHub/文档，可多条）
- **达标机制**：每个计划挂多条达标要求，逐条打勾，全部完成自动达标并触发重排；智能合并（重复跳过、缺失补充、同源更新）
- **自动排程引擎**：结合固定课表 + 强度参数（日负荷上限/块长/精力曲线/连续工作上限），贪心+多因子评分自动排布；排布可解释、容量不足预警
- **固定课表**：手动录入 / 示例课表 / **ICS 日历文件导入**（教务系统、手机日历、Outlook 均可）
- **日/周视图**：日时间轴（当前时间线）+ 本周 7 列概览
- **数据安全**：ChangeLog 追加日志 + 快照；撤销；导出/导入 JSON 备份；全程本地不上传
- **桌面小人**：右下角实时播报（正在做/接下来/达标进度/祝贺演出）

## 核心体验闭环

```
随手新增 → 自动录入 → 结合课表与强度约束自动排布 → 小人按时提醒/陪伴 → 动态重排
```

## 架构总览

```
① 形象交互层    Sprite/Live2D · 气泡对话 · 拖拽互动 · 提醒演出
② 录入层        快捷键浮窗 · 自然语言解析 · 手动表单 · 课表/ICS 导入
③ 排程引擎层    课表管理 · 强度参数 · 贪心评分 → 约束求解 · 增量重排
④ 数据层        本地 SQLite/IndexedDB · 变更日志(ChangeLog) · 同步队列
⑤ 服务集成层    托盘 · 通知 · 开机自启 · 番茄钟 · 统计复盘
⑥ 同步层(可选)  端到端加密 · WebDAV · 手机端轻客户端
```

**关键设计决策**：
- **Task 与 Block 分离**——任务是"做什么"，时间块是"何时做"，重排只动块不动任务；
- **排布是派生数据不同步**——同步只传任务+参数+锁定块，双端各自重算排布；
- **本地优先**——默认全部数据在本地，离线可用，同步是可选项。
