# 路线图（Roadmap）

> 原则：每阶段结束都要能跑、能演示。不要憋大招。

## v0.1 — 单机最小可用版（当前阶段）

- [x] 数据层：SQLite + ChangeLog 追加表（一开始就设计进去）
  - [x] ChangeLog 数据模型已定义（SQLite 落地待做）
- [x] 排程引擎：空闲槽构造 → 多因子评分 → 贪心放置 → 约束校验
  - [x] 通过 `core/tests/engine.test.ts` 全部用例（19/19，v0.2 重排用例按计划跳过）
- [ ] 最简界面：日/周视图 + 计划列表 + 增删改
- [ ] 固定事件导入：ICS 文件 + 手动录入
- [ ] 小人：静态占位图（此阶段不做动画）
- [ ] 发布：GitHub Releases 首个安装包

## v0.2 — 形象与体验

- [ ] 桌面小人：透明置顶窗口 + 鼠标穿透（参考 BongoCat）+ 状态机动画（Sprite）
- [ ] 录入层：全局热键浮窗 + 规则版自然语言解析 + 确认卡
- [ ] LLM 双路由增强（可配 API Key / Ollama 本地模型）
- [ ] 强度参数面板 + 增量重排（锁定块不动原则）
- [ ] 排程结果可解释摘要（"因为 DDL 临近且你上午精力分高"）

## v0.3 — 同步与手机端

- [ ] ChangeLog 文件级同步：WebDAV / 坚果云 / Dropbox
- [ ] 冲突策略：实体级 last-write-wins
- [ ] 手机端轻客户端：查看 / 语音快速新增 / 勾选完成 / 本地提醒
- [ ] 设备配对（扫码绑定）

## v0.4 — 进阶与生态

- [ ] OR-Tools CP-SAT 约束求解器（Python 边车，"先快后好"）
- [ ] ExecutionLog 统计反哺精力曲线（先规则统计，后时序模型）
- [ ] 模型/皮肤开放规范（JSON manifest + 贴图包）+ 社区模型收录仓库
- [ ] CRDT 合并（可选，视多端编辑需求）

## 贯穿性事项

- 每阶段配套：单元测试 → 文档更新 → Release Notes
- 合规：Live2D SDK 单独授权插件化；教务课表只做本地文本解析不爬取
