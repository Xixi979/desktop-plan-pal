# 桌面计划小人 · 使用手册（v0.1）

> 一个住在桌面上的计划管理小助手：随手加计划，它自动帮你排进日程缝隙，还会陪你干活。

## 打开方式

**推荐：双击桌面的 `open-plan-pal.bat`**（自动用 Microsoft Edge 打开，不依赖系统默认浏览器）。

也可以手动打开：找到 `desktop-plan-pal/ui/index.html`，右键 → 打开方式 → **Microsoft Edge**（可勾选"始终"）。

> ⚠️ 请勿在聊天窗口的预览面板里操作（预览面板只用于查看，按钮交互受限）。
> ⚠️ 老内核浏览器（QQ/360/WPS 内置浏览器等）打开会显示"内核过旧"提示，请换 Edge。
> 数据保存在浏览器本机（localStorage），同一台电脑同一浏览器下次打开还在。换电脑或换浏览器时，先「导出数据」再在新环境「导入备份」。

## 三个加计划的方式（⚡ 加计划 面板）

| 方式 | 用法 | 特点 |
|---|---|---|
| ⌨️ 一句话 | 输入"写实验报告 3小时 周五前"点添加 | 自动识别时长 / DDL / 类别；撞上同名计划自动并入并完善达标要求 |
| 🖼️ 图片 | 选图 / 拖图 / Ctrl+V 粘贴截图 | 自动 OCR 识别图中文字生成达标要求；支持一次多张；备注可写"看完第一课、做课后习题 2小时 周五前" |
| 🔗 链接 | 粘贴 B站 / GitHub / 文档链接（可多条） | 自动识别站点、建议标题和类别 |

图片和链接通道都可以选择「新建计划」或「并入某个已有计划」（用于给已有计划补充资料和要求）。

## 达标要求（逐条打勾）

每个计划展开「达标要求 & 资料」：

- 点「➕ 加一条」手动添加要求，或由录入自动生成；
- **逐条勾选**，标题旁实时显示进度（如 2/5）；
- **全部勾完 → 计划自动完成**，腾出的时间自动分给剩余计划；取消任一条 → 自动回到未完成；
- 你手动添加的要求永远不会被自动改写；同来源内容更新时会自动替换旧要求。

## 计划关联资料文件夹

计划详情内可填「资料文件夹路径」（如 `C:\Users\你\Desktop\高数作业`），保存后该计划显示 📁 徽标。

- **📋 复制路径**：一键复制到剪贴板，方便去资源管理器粘贴打开；
- **📂 选择**（Edge/Chrome 且环境支持时显示）：直接选择文件夹，自动列出里面的文件清单，帮你看清「这个计划都有哪些资料」；选择后路径自动保存；
- 桌面端一键打开文件夹在 v0.2 打包（Tauri）后可用。

## 🎛️ AI 智能解析（可选）

「强度参数」面板底部折叠区「🤖 AI 智能解析设置」：

1. 填 OpenAI 兼容接口地址、模型名、API Key，点保存；
2. 之后一句话加计划会先交给大模型理解（更懂「下周三前把PPT弄好」这类复杂表达）；
3. 8 秒无响应或失败会自动退回本地规则解析，功能永不中断；
4. Key 只保存在本机浏览器，不上传任何服务器；点「清除」可随时关闭。

## 📅 固定课表

- 手动添加：名称 + 起止时间 + 每天/仅一次；
- **📥 导入 ICS**：从教务系统 / 手机日历 / Outlook / Google 日历导出 `.ics` 文件直接导入，自动去重；全天事件会跳过并提示；
- 「载入示例课表」可以快速体验。

## 🎛️ 强度参数（自动排程的依据）

- **每日负荷上限**：一天最多排多少分钟任务；
- **单块最长/最短**：一个连续时间块的范围；
- **连续工作上限**：超过会自动插入休息；
- **最小休息间隔**：两块之间的间隔。

改完自动重排。排程只动"时间块"不动"计划"：手动调整过的块会被锁定，重排时不冲掉。

## 🕐 时间轴与周视图

- 日视图：07:00–24:00 时间轴，🔒 固定课表 / 彩色任务块 / ☕ 休息 / 当前时间红线；
- 点标题栏「切周视图」看本周一到周日 7 列概览，今天高亮。

## 右下角的小人

SVG 小机器人，六种状态自动切换：

- **待机**：呼吸+眨眼，气泡告诉你接下来做什么；
- **工作中**：快速起伏+敲键盘，显示当前任务和达标进度；
- **休息中**：摇摆+端茶杯；
- **庆祝**：跳跃+小星星——达标全勾或今日计划全部完成时；
- **疲惫**：流汗——今天剩余任务量超过负荷上限时，提醒你砍单；
- **打瞌睡**：23 点后自动睡觉 zzZ。

## 数据安全

- 数据在本机浏览器，不上传任何服务器；
- **📤 导出数据**：下载 JSON 备份（含全部计划、课表、参数）；
- **📥 导入备份**：选择之前导出的 JSON 恢复（会覆盖当前数据，操作前有确认）；
- **↩️ 撤销**：误删/误改可撤销（导入边界处不可跨撤销）；
- **🗑️ 清空数据**：慎点，有二次确认。

## 常见问题

**Q：按钮点了没反应？**
先看输入框是否为空——空内容会弹提示要求先填写。若确认填写了还没反应，检查页头版本号，然后打开 `ui/selftest.html`（自动诊断页），把页顶黄条的结果截图反馈。

**Q：换了浏览器/电脑，数据没了？**
数据按浏览器存储。先在旧环境「导出数据」，新环境「导入备份」即可。

**Q：OCR 识别不了图片？**
首次使用需联网下载识别模型（约 15MB）。无网络时自动降级为文件名规则，不影响录入。

**Q：导入 ICS 报"跳过 N 条"？**
全天事件（如运动会）无法编排到时间段，会跳过；其余正常导入。
