桌面计划小人 · 使用说明书 v0.2.6

桌宠 × 自动排程的桌面计划助手 —— 把计划交给小人，它帮你排好每一天。

1. 快速上手

  • 启动：双击桌面上的 桌面小人.bat，屏幕上会出现一只悬浮的蓝色小人。
  • 打开主窗口：双击小人，弹出功能主窗口（计划、课表、参数都在这里）。
  • 移动小人：按住小人拖动到屏幕任意位置。
  • 关闭小人：鼠标悬停在小人上，右上方会出现红色 ✕，点击即可退出。
  • 关闭主窗口：直接点窗口右上角的 ✕，小人不受影响。
💡 小人是透明悬浮窗，不占任务栏；主窗口关闭后再双击小人即可随时打开。

2. 桌面小人：六种状态

小人会根据你的计划数据自动变换表情和动作，气泡里会提示接下来要做什么：

状态什么时候出现小人在做什么
🧍 待机没有正在进行的任务呼吸、眨眼，气泡提示下一件事
💻 工作中当前时段排了任务身体起伏 + 手臂敲击，提示「还剩 X 分钟」
🍵 休息中排程的休息块左右摇摆、端着茶杯
🎉 达标庆祝某计划达标 / 今日全部完成跳跃、眼睛变弯、周围冒星星
😥 超载疲惫当日任务超过日负荷上限缓慢摇晃、流汗，提醒你砍任务
😴 打瞌睡深夜，或没有任何计划闭眼，Zzz 上浮

3. 加计划：四种录入方式

点主窗口顶部的 ⚡ 加计划 展开，四种 Tab 任选：

① 一句话录入（最快）

直接输入一句话，自动识别标题 / 时长 / 截止日 / 类别：
写实验报告 3小时 周五前 → 标题「写实验报告」、时长 180 分钟、DDL 周五。

支持接入大模型（OpenAI 兼容接口）做智能解析：在「🎛️ 强度参数」底部填接口地址、模型名、API Key；未配置时用内置规则解析，接口失败也会自动降级，不影响使用。

② 图片录入

  • 支持多选 / 拖入 / Ctrl+V 粘贴，自动压缩成缩略图（最多 12 张，可移除）。
  • 图片里的文字会自动 OCR 识别，并入「达标要求来源」（可编辑）。
  • 计划名称、类别可自定义；没有文字时按文件名生成达标要求。

③ 链接录入

  • 一次粘贴多条链接（空格或换行分隔）：B站视频、GitHub、在线文档、网课……
  • 常见网站自动识别标题；每条链接自动生成「查看内容 + 整理要点」达标项。

④ 手动表单

精确填写标题、类别、预计分钟数，适合一句话说不清的任务。

💡 一句话录入时，如果标题和已有计划同名，会自动并入该计划而不是新建。

4. 达标机制：把「做完了」说清楚

  • 每个计划有一份达标清单（来源：备注按「、」「；」拆分，或图片 OCR、链接自动生成）。
  • 逐条打勾 ✅；全部达标 → 计划自动变为「已完成」，小人跳起来庆祝 🎉。
  • 取消任意一条 → 计划自动退回「已排期」，重新参与排程。
  • 悬停条目可 ✏️ 修改 文字、✕ 删除 不要的条目。

5. 固定课表：不被打扰的硬时间

点 📅 固定课表 展开。课表时间不参与自动排程，排程时会自动避开。

四种添加方式

  • 手动添加：填名称、星期、起止时间。
  • 批量文字行：每行一门课，格式 高等数学 周一 08:00-09:40 或 大学英语 星期三 第3-4节。
  • 📥 导入 ICS：日历文件一键导入。
  • 📷 图片导入课表（v0.2.6 重点增强）：
    • 支持教务系统「节次 × 星期」网格课表截图/照片（如首经贸研究生课表）：自动按列头星期、行头节次定位，识别每格课名，连节课自动合并。
    • 也支持文字行式课表图片。
    • 首次使用需联网下载中文识别模型（约 20~60 秒），请耐心等待提示。
    • 时间按默认 13 节制作息表换算，导入后每门课可 ✏️ 修改；OCR 个别错字（如「挖掘」认成「控握」）悬停手改即可。
💡 课表条目悬停出现 ✏️ 和 ✕，可随时改时间、换星期或删除。

6. 自动排程：把计划塞进空闲时间

  • 排程引擎自动找今天的空闲时段（避开课表、过去时间、休息），按多因子评分（DDL 紧急度、时长匹配、类别轮转等）把任务放进时间轴。
  • 🔄 重新排程：推倒重排。增量重排会保留已结束/进行中的块，只重排未来的，不打断你正在做的事。
  • ↩️ 撤销：排程结果不满意一键回退。
  • 🕐 今日时间轴：查看今天每个时段安排了什么；小人状态与时间轴实时联动。
  • 当日任务总量超过日负荷上限时，小人会变疲惫脸提醒你砍掉或顺延一些。

7. 强度参数：按自己的节奏来

点 🎛️ 强度参数 展开，6 个参数随意调：

参数含义默认思路
日负荷上限一天最多安排多少分钟任务超了小人会提醒
单块上限 / 下限每个任务块的最长 / 最短时长大任务自动切块
最小休息两个工作块之间的休息时长自动生成休息块
连续工作上限最多连续工作多久到点强制休息
精力类型上午型 / 夜猫型等影响时段评分偏好

8. 数据与备份

  • 所有数据保存在本机本地（浏览器本地存储），不上传任何服务器。
  • 📤 导出数据：一键导出 JSON 备份文件。
  • 📥 导入备份：换电脑或误删后可恢复。
  • 🗑️ 清空数据（红色，谨慎使用）：清空全部本地数据，建议先导出备份。
⚠️ 清空前请务必先导出备份；主窗口若提示「版本过旧」，关闭窗口重新双击小人打开即可加载新版。

9. 常见问题

Q：双击小人没反应？

确认 桌面小人.bat 启动的小人还在运行（悬停看 ✕）；若进程被杀，重新双击 bat 即可，数据不丢。

Q：课表图片识别失败或没解析出课程？

① 确认照片清晰、方向正、已联网；② 网格课表需要能看到「星期一~五」列头和「节次」行头；③ 实在不行改用手动或文字行方式添加。

Q：导入的课程时间不对？

时间按默认 13 节制作息表估算，各校节次时间不同——导入后悬停 ✏️ 修改起止时间即可。

Q：主窗口按钮全部失灵或提示模块缺失？

说明窗口加载的是旧版构建：关闭主窗口，重新双击小人打开（页头可看版本号 v0.2.6）。

Q：任务会传到云端吗？

不会。全部数据只在本地；配了大模型接口时，仅「一句话文本」会发给你自己填的接口地址。
